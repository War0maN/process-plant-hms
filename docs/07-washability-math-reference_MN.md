# Washability тооцооллын математик лавлагаа

**Зорилго:** Фракцын шинжилгээний (sink-float) хүснэгтийн багана бүрийн томьёог
тодорхой болгож, `engine/washability.py`-ийн ground-truth болгох.
**Эх сурвалж:** Cowork-тэй хийсэн домэйн яриа + ISO 1170 / ISO 923 стандарт.
**Баталгаажуулалт:** `tests/test_worksheet.py`, `tests/test_washability.py`.

## 1. Үнслэг: ad → d хөрвүүлэлт (ISO 1170)

Лаб дээж агаар-хуурай (ad) төлөвт шинжлэгддэг (байгалийн чийг үлдсэн). Баяжуулалтын
тооцоо абсолют хуурай (d) суурьтай тул чийгийг хасна:

$$\text{Ash}_d = \dfrac{\text{Ash}_{ad}}{1 - M_{ad}/100}$$

- Чийг **хасагдах** тул үнс **ӨСНӨ** (буурахгүй).
- Шалгалт: `11.45 / (1 − 0.80/100) = 11.542%` ✓
- ⚠ Зарим эх сурвалжид `Ash_d = Ash_ad × (100−M)/100` гэж бичсэн нь **буруу чиглэл**
  (үнс буурна). Зөв нь дээрх — хуваах.
- Код: `engine.washability.to_dry_basis(ash_ad, moisture_ad)`

---

## 2. Q. of Mass (үнслэгийн үржвэр масс)

$$Q = \text{Mass}\% \times \text{Ash}_d$$

- Энэ нь жинлэгдсэн дундаж үнс бодох коэффициент (нэгж: %·%).
- Утга: тухайн фракц дахь "цэвэр үнсний харьцангуй масс".
- Нийт дундаж үнс = `ΣQ / ΣMass`. Жишээ: `2848.7 / 100 = 28.49%`.

---

## 3. Cumulative Floats (хөвөгч — баяжмал)

Хөнгөнөөс хүнд рүү (дээрээс доош) хуримтлуулна:

$$\text{CumFloat Mass}(d)=\sum_{\rho \le d}\text{Mass}, \quad
\text{CumFloat Ash}(d)=\frac{\sum_{\rho \le d} Q}{\sum_{\rho \le d}\text{Mass}}$$

- d дээр хагалбал баяжмалын онолын **гарц** ба **үнс**.
- Код: `clean_ash_at`, `yield_at`, worksheet-ийн `cum_float_*`.

---

## 4. Cumulative Sinks (живэгч — хаягдал)

Хүнднээс хөнгөн рүү (доороос дээш) хуримтлуулна:

$$\text{CumSink Mass}(d)=\text{Нийт}-\text{CumFloat Mass}(d)$$

- Хамгийн дээд мөрөнд `CumSink Mass = 100%`, `CumSink Ash = нийт дундаж үнс`
  (баланс шалгалт).

---

## 5. NGM / NDM — near-gravity material (⚠ КОНВЕНЦ ЧУХАЛ)

Хагалах нягтын орчмын тогтворгүй материал. **Цонхны өргөнөөр хоёр янзаар** тоологддог:

| Конвенц | Нэг талын өргөн | Нийт өргөн | Хаана |
|---------|------------------|------------|-------|
| **Bird / сурах бичиг** | ±0.10 | 0.20 | Doc 02 §5.3, хүндрэлийн жиш (доор) |
| **ISO 923 narrow** | ±0.05 | 0.10 | Зарим лабын worksheet (Book2 байж магадгүй) |

$$\text{NGM}(d) = \sum \text{Mass}\% \in (d-\text{hw},\; d+\text{hw}]$$

- Хоёр конвенц **~2 дахин өөр** тоо өгнө → хүндрэлийн босготой **ИЖИЛ** конвенц ашиглана.
- **Жигд бус бин:** бин цонхноос өргөн бол (ж: 1.50–1.60 = 0.1) биний массыг
  жигд тархсан гэж үзэж **шугаман интерполяци** хийнэ. Код `_mass_within` үүнийг хийдэг.
- Код: `ngm_at(fr, d, half_width)`; config `engine.ngm_half_width`.

### Хүндрэлийн жиш (±0.10 конвенцоор — Bird)
| NGM % | Угаагдах чанар |
|-------|-----------------|
| 0–7 | Маш амархан |
| 7–10 | Амархан |
| 10–15 | Дундаж |
| 15–25 | Хэцүү |
| >25 | Туйлын хэцүү (нягт ±0.005 савлахад чулуу үсэрнэ) |

> **⚠ Шийдвэрлэх асуудал (инженерт):** Book2 worksheet ±0.05-аар бодсон бол,
> дээрх >25% босго (±0.10-д тохирсон) шууд хэрэглэвэл буруу пессимист болно.
> Book2-ыг тулгаж, аль конвенцийг стандарт болгохыг баталгаажуулна.

## 6. 1/RD ба Elementary Ash Curve

- RD = бин дундаж нягт `(lo+hi)/2`. SG (Specific Gravity) = RD (нэгжгүй, усанд харьцуулсан).
- `1/RD` — үнс vs нягтын хамаарлыг **шугаман** болгох (linearization) X координат.
  Үүгээр Elementary Ash Curve тэгшхэн шулуун болж, дурын нягт дээрх үнсийг
  интерполяцоор нарийн боддог.
- Worksheet дахь `SG: 7, 14, 21...` нь **зөвхөн Excel chart-ийн жигд алхам** —
  физик утгагүй, engine-д ашиглахгүй.
- Код: `inv_rd(f)`, `mid_rd(f)`.

## 7. Henry-Reinhard 5 муруй (товч)

| Муруй | Тэнхлэг | Юу заана |
|-------|---------|----------|
| Улаан — Cum Float | Үнс ↔ Гарц | Зорилтот үнсэд хүрэх онолын дээд гарц |
| Шар — Elementary Ash | Гарц ↔ Үнс | Cut ирмэг дээрх нүүрсний бодит үнс |
| Хөх — Cum Sink | Үнс ↔ Гарц | Хаягдлын гарц/үнс |
| Цэнхэр тас. — NGM | Нягт ↔ Гарц | Хагалах орчмын тогтворгүй материал |
| Хар — RD/Mean | Нягт ↔ Гарц | Нягт↔гарцын шууд хамаарал |

> Тэнхлэгийн дүрэм: Cum Float тэнхлэгийг **урвуу** (дээр 0, доор 100) харуулна.

## 8. Engine-д юу орох вэ

- **Зөвхөн composite (нэгдсэн) баганыг** орлогт ашиглана. Size-class задаргааны
  зарим Ash багана нь "гибрид" (size-class жигнэлт + ad→d хольсон) тул цэвэр
  томьёотой таарахгүй — engine-д ашиглахгүй, зөвхөн лавлагаа.
- Engine washability-г **d (хуурай) суурьтай** хүлээж авна. Хэрэв raw нь ad бол
  эхлээд `to_dry_basis`-аар хөрвүүлнэ.
