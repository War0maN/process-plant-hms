# Нээлттэй зүйлсийн жагсаалт — Үйлдвэрийн төслийн документууд

**Үүсгэсэн:** 2026-05-22 · Claude
**Шинэчилсэн:** 2026-05-22 — нээлттэй зүйл бүрт **дэлхийн жишиг + жишээ утга** нэмэв
**Зорилго:** Төслийн документуудад бичигдсэн, хариу хүлээж буй БҮХ `[DUK INPUT NEEDED]`, `[VERIFY]`, `[CLARIFY]` тэмдэглэгээг нэг жагсаалтад цуглуулж, юу ч мартагдахгүй байх.
**Хэрэглэх заавар:** Тухайн зүйлийг эх документ дээр бөглөж дуусгасан үед нүдийг нь тэмдэглэнэ. Энэ файл бол зөвхөн **хяналтын жагсаалт** — жинхэнэ хариултууд нь Doc 02, Doc 03 руу буцаж бичигдэнэ.

> **Дэлхийн жишгийг хэрхэн ашиглах вэ.** Зүйл бүрийн доор нэмсэн **Дэлхийн жишиг** ба **Жишээ** нь танай үйлдвэрийн жинхэнэ утга **БИШ**. Эдгээр нь: (1) эхлэх лавлагаа цэг, (2) "миний тоо логиктой юу" гэдгийг шалгах sanity-check. Жинхэнэ утгыг танай үйлдвэрээс ав; жишиг нь зөвхөн "ямар орчимд байх ёстойг" хэлж байгаа. Танай тоо жишгээс эрс зөрвөл — буруу гэсэн үг биш, гэхдээ дахин шалгах дохио.

## 1. Doc 02 — Домэйн мэдлэг — нээлттэй зүйлс + дэлхийн жишиг

### Процессын онол ба циклон

- [ ] **§1.2** `[VERIFY]` — Циклоны d₅₀ ба орчны SG-ийн зөрүү
  - **Дэлхийн жишиг:** Нүүрсний DM циклонд хагалах нягт d₅₀ нь циклонд тэжээгдэж буй "зөв орчны" (correct medium) нягтаас бага зэрэг **өндөр** байдаг. Ердийн зөрүү **+0.02 – 0.10 g/cm³**. Циклоны хэмжээ, орчин/нүүрсний харьцаа, тэжээлийн даралт, тогтвортой байдлаас хамаарна.
  - **Жишээ:** зөв орчин 1.35 → d₅₀ ≈ 1.40 (зөрүү +0.05).
  - **Тэмдэглэл:** Doc 02 MN §1.2-т "0.002" гэж таамагласан нь хэт бага (магадгүй 0.02-ын бичгийн алдаа). Бодит зөрүү ~0.02–0.10 — засах хэрэгтэй.

- [ ] **§1.3** `[VERIFY]` — Жишгийн Ep (магадлалт алдаа)
  - **Дэлхийн жишиг:** Сайн ажиллагаатай нүүрсний DM циклоны Ep ердийн **0.015 – 0.04 g/cm³**. Танай Doc 02 MN §1.3-ийн хүснэгт (<0.025 маш сайн, 0.025–0.040 хэвийн, 0.040–0.060 дундаж, >0.060 муу) нь дэлхийн жишигтэй бүрэн нийцэж байна — өөрчлөх шаардлагагүй.
  - **Жишээ:** эрүүл primary коксжих цикл ~0.02–0.03.

- [ ] **§1.6** `[DUK]` — Схемийн тохиргоо (хоёр / гурван бүтээгдэхүүнт)
  - **Дэлхийн жишиг:** Коксжих нүүрсний ихэнх үйлдвэр **хоёр шатлалт** (primary + secondary) эсвэл **гурван бүтээгдэхүүнт** циклон ашигладаг. Циклон тус бүр голдуу two-product.
  - **Жишээ:** Reference Plant A нь яг хоёр шатлалт, two-product × 2 — энэ нь хариулагдсан (Doc 03 §2).

- [ ] **§3.4** `[VERIFY]` — Vortex finder ажиллах хугацаа
  - **Дэлхийн жишиг:** Керамик (alumina) доторлогоотой **8,000 – 15,000 ц**; полиуретан / металл **2,000 – 4,000 ц**.
  - **Жишээ:** alumina-той vortex finder ~10,000–12,000 ц.

- [ ] **§3.4** `[VERIFY]` — Spigot ажиллах хугацаа
  - **Дэлхийн жишиг:** Керамик **6,000 – 12,000 ц**; PU / резин **1,000 – 2,500 ц**. Spigot нь vortex finder-ээс **хурдан** элэгдэнэ (хамгийн хүнд урсгалд байдаг).
  - **Жишээ:** alumina spigot ~7,000–9,000 ц.

- [ ] **§3.5** `[DUK]` — Vortex finder / spigot материал
  - **Дэлхийн жишиг:** Alumina керамик (ихэвчлэн 95% alumina, "K95") нь нүүрсний DMC элэгдлийн эд ангийн дэлхийн стандарт. Зарим нь SiC, базальт, Ni-hard металл.
  - **Жишээ:** Reference Plant A — alumina 25 мм (хариулагдсан, Doc 03 §3).

### Магнетит ба орчин

- [ ] **§2.4** `[VERIFY]` — Нягтыг яаж хянадаг (гар / автомат)
  - **Дэлхийн жишиг:** Дэлхийн стандарт — гамма (nuclear) density gauge → автомат хяналтын loop → make-up магнетит ба шингэлэх усыг тохируулна. Хуучин / жижиг үйлдвэрт гар хяналт хэвээр.
  - **Жишээ:** гамма gauge → PID контроллер → make-up хавхлага.

- [ ] **§2.5** `[DUK]` — Магнетитийн өртөг ($/тонн) ба алдагдал
  - **Дэлхийн жишиг:** DM-зэрэглэлийн магнетит ойролцоогоор **$80 – 250/тонн** хүргэгдсэн үнэ (эх үүсвэр, хүргэлтийн зайнаас ихээхэн хамаарна). Алдагдал: сайн практик **0.5 – 1.5 кг/т**; >2 кг/т бол асуудалтай.
  - **Жишээ:** Reference Plant A нь 0.6 кг/т — жишгийн доод хязгаараас ч сайн (хариулагдсан, Doc 03 §7).
  - **Тэмдэглэл:** Үнэ нь зах зээлээр хэлбэлздэг — одоогийн бодит үнийг нийлүүлэгчээс шалга.

### Насос

- [ ] **§4.4** `[DUK]` — Кавитацийн асуудал ба шалтгаан
  - **Дэлхийн жишиг:** Нийтлэг шалтгаан — feed зумпны түвшин бага (агаар сорох), шлам/зуурамтгай ихсэх, impeller элэгдсэн, NPSH хүрэлцээгүй, сорох шугам бөглөрөх.
  - **Жишээ:** Reference Plant A — зумпны түвшин унах + шлам хуримтлал (Doc 02 MN §4.4-т хариулсан).

### Үнс → нягтын логик

- [ ] **§5.3** `[VERIFY]` — Жишгийн NDM (ойролцоо нягттай материал)
  - **Дэлхийн жишиг:** ±0.1 g/cm³ дотор — амар нүүрс **<10%**, дунд **10–20%**, хүнд **20–25%**, маш хүнд **>25%**.
  - **Жишээ:** дунд зэргийн коксжих нүүрс, cut 1.40 → NDM ~15–20%.
  - **Тэмдэглэл:** NDM-ийг таамаглахгүй — washability өгөгдлөөс **тооцоолно** (Doc 03 §12-ийн seam хүснэгтээс).

- [ ] **§5.4** `[VERIFY]` — Гарц / үнсний харьцаа
  - **Дэлхийн жишиг:** Cut нягтыг **+0.02 g/cm³** өсгөхөд → гарц **+1–3%**, баяжмалын үнс **+0.3–0.8%**. Washability муруйгаас хамаарна.
  - **Жишээ:** ердийн коксжих cut дээр +0.02 → +2% гарц, +0.5% үнс.
  - **Тэмдэглэл:** Doc 02 MN §5.4-т Duk үүнийг аль хэдийн баталгаажуулсан `[VERIFIED]`.

### Тэжээлийн хувьсал ба proxy

- [ ] **§6.2** `[DUK]` — Тэжээлийн гэнэтийн өөрчлөлт хэрхэн илэрдэг
  - **Дэлхийн жишиг:** Насосны мотор гүйдэл өөрчлөгдөх, циклоны даралт хэлбэлзэх, урсгалын харагдац, зумпны түвшин савлах, туузан дээрх нүүрс/чулууны харьцаа, online ash analyzer.
  - **Жишээ:** Reference Plant A — Doc 02 MN §6.3-т хариулсан.

- [ ] **§7.3** `[DUK]` — Туршлагаас ашигласан өөр proxy
  - **Дэлхийн жишиг:** Орчин/нүүрсний харьцаа (medium-to-coal ratio), магнетитийн эргэлтийн ачаалал, ялгаврын гарц (yield-by-difference, туузан жингээр), under/overflow нягтын зөрүү, densifier циклоны төлөв, шүүрийн ус зайлуулалтын үр дүн.

### §9 — Практикийн эмпирик дүрэм ("таны 20 жил")

> **Бүх §9 зүйлсийг Duk аль хэдийн Doc 02 MN §9-д бөглөсөн.** Доорх дэлхийн жишгүүд нь танай бичсэн утгууд **зөв эсэхийг баталгаажуулж** байна — бараг бүгд нийцэж байна. Англи хувилбар л хоцорч байгаа.

- [ ] **§9.1** — Тэжээлийн үнс +2% → орчны нягт
  - **Дэлхийн жишиг:** Үнс өсвөл нягтыг **−0.01...−0.02 g/cm³** буулгаж хагалбарыг хөнгөрүүлнэ (баяжмалын чанар барих). Танай Doc 02 MN §9.1 — нийцнэ.

- [ ] **§9.1** — Тэжээлийн чийг +2% → үйлдэл
  - **Дэлхийн жишиг:** Feed rate **−10...−15%**, make-up магнетит нэмэх (ус шингэрүүлэхээс сэргийлэх). Танай утга — нийцнэ.

- [ ] **§9.1** — Шинэ ROM давхрага → overdose хугацаа
  - **Дэлхийн жишиг:** Эхний **24–48 ц** консерватив (бага) нягт барих. Танай утга — нийцнэ.

- [ ] **§9.2** — "Хангалттай" vortex finder элэгдэл
  - **Дэлхийн жишиг:** Насос хэвийн үед циклоны даралт **10–15%** буурах. Танай утга — нийцнэ.

- [ ] **§9.2** — Spigot хурдан элэгдлийн шинж
  - **Дэлхийн жишиг:** Урсгал "шүхэр"-ээс "олс" (rope) болох, баяжмалын үнс **0.5–1.0%** шалтгаангүй өсөх. Танай утга — нийцнэ.

- [ ] **§9.2** — Насосны impeller солих
  - **Дэлхийн жишиг:** VFD **95–100%**-д тулж хэвийн даралт гаргах + кавитацийн чичиргээ; ердийн **3,000–5,000 ц**. Танай утга — нийцнэ.

- [ ] **§9.3** — Хамгийн бага сайн make-up хурд
  - **Дэлхийн жишиг:** **0.8–1.2 кг/т**. (Reference Plant A 0.6 кг/т — энэ жишгээс ч сайн.)

- [ ] **§9.3** — "Магнетит алдагдал хэт их" босго
  - **Дэлхийн жишиг:** **>1.5–2.0 кг/т**. Танай утга — нийцнэ.

- [ ] **§9.3** — Шламын бохирдол илрүүлэх
  - **Дэлхийн жишиг:** Зуурамтгай ↑, циклоны даралт **20–30 kPa** шалтгаангүй ↑, magnetic separator банн халих. Танай утга — нийцнэ.

- [ ] **§9.4** — Дээд ширхэг өөрчлөгдөх → циклоны хүчин чадал
  - **Дэлхийн жишиг:** Top size огцом өсвөл throughput **−20...−30%**, бутлуур шалгах. Танай утга — нийцнэ.

- [ ] **§9.4** — Тэжээлийн нарийн фракц өндөр үед
  - **Дэлхийн жишиг:** Desliming шүүрийн шүршигчийн даралт ↑, нарийн шламыг флотаци руу зайлуулах. Танай утга — нийцнэ.

- [ ] **§9.5** — "Сэжиглэж эхлэх" нөхцлийн жагсаалт
  - **Дэлхийн жишиг:** Танай 3 бичсэн (насос ампер хэвийн ч даралт унах; rinse шүүр дээр хөөс = исэлдсэн нүүрс; орчны зумп шалтгаангүй өсөх = шингэрэлт). Нэмэлт нийтлэг: overflow дээр чулуу харагдах, underflow олсолж эхлэх, density gauge SP-ээс байнга зөрөх.

### §4 — Масс баланс / feed rate (2 `[DUK]` + 1 `[CLARIFY]`)

- [ ] **§4.2** `[DUK]` — Overflow-ийн Хатуу биет R.D. ба Орчин R.D. (Primary) — *Duk: "энд би яах ёстой билээ сайн ойлгохгүй байна"*
  - **Тайлбар (эргэлзээг тайлъя):** Циклон зөвхөн нүүрсийг биш, **орчныг (магнетитийг) ч ангилдаг**. Тиймээс:
    - *Overflow орчны R.D.* — overflow руу гарах орчин нь **шингэрсэн** (магнетит багатай), тэжээлийн орчноос ердийн **0.05–0.15 g/cm³ доогуур**.
    - *Underflow орчны R.D.* — underflow руу гарах орчин нь **өтгөрсөн**, тэжээлийн орчноос дээгүүр. Under/overflow орчны зөрүү ("density differential") нь DMC-ийн чухал үзүүлэлт — ердийн **0.2–0.4 g/cm³**.
    - *Overflow Хатуу биет R.D.* — баяжмал коксжих нүүрсний дундаж хувийн жин; цэвэр коксжих нүүрс ердийн **1.30–1.45**.
  - **Юу хийх вэ:** Эдгээр нь үйлдвэрийн **зураг төслийн (design) масс балансын** тоо. Plant-ийн design flowsheet байвал тэндээс шууд ав. Байхгүй бол доорх жишгээр түр бөглө.
  - **Жишээ:** тэжээлийн орчин 1.45 → overflow орчин ~1.35, underflow орчин ~1.60; overflow Хатуу биет R.D. ~1.40.

- [x] Доод хязгаар (<1.2 мм) → TBS (−1.2+0.25 мм) ба флотаци (−0.25 мм)
- [x] Дээд хязгаар (>50 мм) → +50 мм ≤5% журамтай, дахин буталдаггүй

### §6 — Орчны нягт ба ажиллах хязгаар (2 `[DUK]` + 1 `[CLARIFY]`)

- [ ] `[DUK]` — Нягтын ажиллах хязгаар (min/max)
  - **Дэлхийн жишиг:** Коксжих нүүрсний DMC зөв орчин ердийн **1.30–1.50 g/cm³**; эрчим хүчний **1.50–1.80**.
  - **Жишээ:** Reference Plant A — Primary min/max ~**1.28–1.40**, Secondary ~**1.45–1.60** (Duk-ийн өгсөн 1.30–1.36 / 1.48–1.55 ажлын утгаас бага зэрэг өргөтгөв).

- [ ] `[DUK]` — Нягт хэмжих арга
  - **Дэлхийн жишиг:** Гамма (nuclear) density gauge нь DMC-ийн дэлхийн стандарт; зарим U-tube / dP (differential pressure).
  - **Жишээ:** циклоны feed шугам дээрх гамма density gauge.

- [ ] `[CLARIFY]` — §1.1-ийн 1.30–1.35 g/cm³-ийг §4-ийн орчны R.D. 1.5-тай нийцүүлэх. **Чухал — SP логикийн гол оролт.**
  - **Тайлбар:** Density gauge нь **"зөв орчны нягт"**-ыг хэмждэг — энэ нь таны SP. Хагалах нягт d₅₀ = зөв орчны нягт + зөрүү (0.02–0.10). §4 масс балансын "1.5" нь зураг төслийн (nameplate) тоо байх магадлалтай; бодит ажиллагаа Primary дээр 1.30–1.36 (Duk баталсан). **SP логик нь БОДИТ утгыг ашиглана**, design 1.5-ыг биш.
  - **Жишээ:** Primary зөв орчин 1.33 → d₅₀ ≈ 1.38–1.43.
  - **Хийх зүйл:** Duk — §4-ийн "1.5" нь зураг төслийн тоо мөн үү, эсвэл өөр урсгалын (өтгөрүүлсэн) орчин уу? Баталгаажуулна уу.

### §7 — Магнетит (3 `[DUK]` + 1 `[VERIFY]`)

- [ ] `[DUK]` — Магнитлаг чанар (% магнитад татагдах)
  - **Дэлхийн жишиг:** DM-зэрэглэлийн магнетит **≥95%** магнитад татагдах (Davis Tube Recovery тестээр). Зарим спек ≥93%.
  - **Жишээ:** 96% магнетит агуулга.

- [ ] `[DUK]` — Нийлүүлэгч / эх үүсвэр
  - **Дэлхийн жишиг:** Магнетит нь голдуу төмрийн хүдрийн баяжуулалтын дайвар бүтээгдэхүүн. Монголд дотоодын эх үүсвэр эсвэл Хятадаас импорт.
  - **Тэмдэглэл:** Энэ нь үйлдвэр тус бүрийн — жишиг тоо байхгүй, зөвхөн чиглэл.

- [ ] `[DUK]` — Үнэ ($/тонн)
  - **Дэлхийн жишиг:** ~**$80–250/тонн** хүргэгдсэн (хэлбэлзэлтэй, хүргэлтийн зайнаас ихээхэн хамаарна).
  - **Тэмдэглэл:** Зах зээлийн үнэ — одоогийн бодит үнийг нийлүүлэгчээс шалга.

- [ ] `[VERIFY]` — 600 г/т хэрэглээ тогтмол үзүүлэлт мөн үү?
  - **Дэлхийн жишиг:** Сайн практик 0.5–1.5 кг/т; 0.6 кг/т нь маш сайн.
  - **Хийх зүйл:** 600 г/т нь жилийн тогтмол дундаж мөн үү, эсвэл нэг сайн сарын тоо мөн үү — баталгаажуул.

### §8 — Орчны recovery систем (1)

- [ ] `[DUK]` — Magnetic separator тоо/хэмжээ; density tank make-up автомат уу, гар уу?
  - **Дэлхийн жишиг:** DMC үйлдвэрт орчны цикл тус бүрт **1–2 magnetic separator**; drum диаметр 900–1200 мм, урт 1.8–3 м. Density tank make-up: орчин үеийн үйлдвэрт автомат; хуучин/жижигт гар.
  - **Жишээ:** Reference Plant A — Duk-ийн хэлснээр гар (усан буугаар) make-up.

### §9 — Насос (8 — 4 талбар × Primary/Secondary)

- [ ] Насосны загвар / үйлдвэрлэгч — Primary / Secondary
  - **Дэлхийн жишиг:** DMC feed pump нь хүнд даацын центрифугаль slurry pump. Нийтлэг брэнд — Warman/Weir (AH, MCR цуврал), Metso/Sala, KSB, GIW.
  - **Тэмдэглэл:** Загварын нэр нь үйлдвэр тус бүрийн — жишиг утга байхгүй, зөвхөн чиглэл.

- [ ] Моторын чадал (кВт) — Primary / Secondary
  - **Дэлхийн жишиг:** Том primary DMC feed pump (~2400 m³/h орчны зутан, өндөрт байрласан циклон руу шахна) → мотор ердийн **315–560 кВт**. Secondary жижиг → **110–250 кВт**. Циклоны өндөр, шугамын урт, орчны нягтаас хамаарч хэлбэлзэнэ.
  - **Жишээ:** Primary ~450 кВт, Secondary ~160 кВт.

- [ ] Хурд хянах арга (VFD?) — Primary / Secondary
  - **Дэлхийн жишиг:** 2011 оны үеийн орчин үеийн үйлдвэр ихэвчлэн DMC feed pump дээр **VFD-тэй**; зарим нь тогтмол хурдтай.
  - **ЧУХАЛ:** Хэрэв VFD байхгүй бол **pump speed нь SP болж ашиглагдахгүй** — энэ нь SP логикийг шууд өөрчилнө. Заавал хамгийн түрүүнд тодруул.

- [ ] Ажлын rpm хүрээ — Primary / Secondary
  - **Дэлхийн жишиг:** Том slurry pump ~**400–900 rpm**.
  - **Жишээ:** ажлын хүрээ 600–750 rpm.

### §10 — Хэмжих хэрэгсэл ба PLC tag (12) — *"хамгийн чухал" гэж тэмдэглэсэн*

> **Дэлхийн жишиг (бүх 11 хэмжүүрт нийтлэг).** Сайн тоноглогдсон DMC цикл дараахыг хэмжих ёстой: зөв орчны нягт (циклон тус бүр), циклоны feed даралт, feed/орчны урсгал, pump speed (VFD %), pump мотор гүйдэл, зумпны түвшин, magnetic separator мотор гүйдэл, make-up усны урсгал, түүхий нүүрсний туузан жин, баяжмал/хаягдлын туузан жин, online ash analyzer (байвал). PLC tag-ийн **нэр** нь үйлдвэр тус бүрийн — жишиг байхгүй; харин дээрх **сигналууд байх ёстой**.

- [ ] Орчны нягт (Primary / Secondary) — хэмжигдэх ёстой (γ-gauge). SP-ийн гол оролт.
- [ ] Циклоны оролтын даралт (Primary / Secondary) — хэмжигдэх ёстой. Элэгдлийн proxy.
- [ ] Тэжээлийн урсгал (flow) — хэмжигдэх ёстой (mag-flow).
- [ ] Насосны хурд (VFD %) — хэмжигдэх ёстой (VFD байгаа бол). SP2.
- [ ] Насосны моторын гүйдэл (A) — хэмжигдэх ёстой. Slurry SG ба элэгдлийн proxy.
- [ ] Зумпны түвшин — хэмжигдэх ёстой. Кавитацийн эрсдэл.
- [ ] Magnetic separator гүйдэл — хэмжигдэх ёстой. Магнетитийн эргэлтийн төлөв.
- [ ] Туузан жин (feed t/h) — хэмжигдэх ёстой. Throughput.
- [ ] Online ash analyzer — байвал маш сайн (PGNAA / dual-energy γ). Олон үйлдвэрт байдаггүй.
- [ ] `[DUK]` — PLC брэнд ба OPC UA
  - **Дэлхийн жишиг:** Нүүрс баяжуулалтад хамгийн нийтлэг — Siemens S7, Allen-Bradley / Rockwell ControlLogix; Schneider бас түгээмэл. OPC UA — 2010 оноос хойшхи SCADA ихэвчлэн дэмждэг, эсвэл gateway-ээр (жишээ нь Kepware) холбоно.
  - **Жишээ:** Siemens S7-300/400 + WinCC, OPC UA сервертэй.

### §11 — Бүтээгдэхүүний зорилт (6 — 3 талбар × 2 бүтээгдэхүүн)

- [ ] Коксжих нүүрс — зорилтот үнс%
  - **Дэлхийн жишиг:** Хатуу коксжих нүүрсний (HCC) баяжмалын үнс ердийн **8.0–10.5%** (премиум HCC <9.5%). Монголын Говийн HCC голдуу ~9.5–10.5%.
  - **Жишээ:** зорилтот үнс 10.5%.

- [ ] Коксжих нүүрс — бусад спек
  - **Дэлхийн жишиг:** Дэгдэмхий бодис (VM), CSN/FSI (коксжихэд 4–9), нийт чийг, хүхэр (<0.6–1.0%), фосфор, плacтометрийн үзүүлэлт.

- [ ] Коксжих нүүрс — гэрээний бүтэц
  - **Дэлхийн жишиг:** Чанарт суурилсан үнэ — үнс/илчлэг/чийг/хүхрийн bonus-penalty, татгалзах хязгаар.

- [ ] Эрчим хүчний нүүрс — зорилтот үнс%
  - **Дэлхийн жишиг:** Эрчим хүчний нүүрсийг ихэвчлэн **илчлэгээр** (NAR/GAR) зардаг; үнс 15–30% зах зээлээс хамаарч зөвшөөрөгдөнө.

- [ ] Эрчим хүчний нүүрс — бусад спек
  - **Дэлхийн жишиг:** Илчлэг (жишээ ~5000–5500 ккал/кг GAR), чийг, хүхэр, дэгдэмхий бодис.

- [ ] Эрчим хүчний нүүрс — гэрээний бүтэц
  - **Дэлхийн жишиг:** Илчлэгт суурилсан үнэ, чанарын penalty.

### §12 — Washability (1)

- [ ] `[DUK]` — Seam бүрийн washability хүснэгт хавсаргах
  - **Тэмдэглэл:** Энэ нь жишиг тоо биш — танай үйлдвэрийн жинхэнэ өгөгдөл. Seam бүрийн float-sink хүснэгтийг өгөхөд бид NDM (±0.1), washability муруй, cut-density хамаарлыг тооцоолно.
  - **Дэлхийн жишиг (хэлбэр):** washability хүснэгт нь нягтын фракц (жишээ −1.30, 1.30–1.40, 1.40–1.50, 1.50–1.60, +1.60), фракц бүрийн жингийн %, үнс % агуулна.

### §13 — Тоног төхөөрөмжийн элэгдлийн baseline (4)

- [ ] Vortex finder (Alumina) ажиллах хугацаа
  - **Дэлхийн жишиг:** Alumina керамик **8,000–15,000 ц**.

- [ ] Spigot / apex (Alumina) ажиллах хугацаа
  - **Дэлхийн жишиг:** Alumina керамик **6,000–12,000 ц** (vortex finder-ээс хурдан элэгдэнэ).

- [ ] Насосны impeller ажиллах хугацаа
  - **Дэлхийн жишиг:** High-chrome impeller, DM duty — **2,000–6,000 ц** (орчин/нүүрсний харьцаа, хатуулгаас хамаарна).

- [ ] Циклоны конусын доторлогооны ажиллах хугацаа
  - **Дэлхийн жишиг:** Керамик доторлогоотой конус **10,000–25,000 ц**.
