# 05 — Үйлдвэрийн дата цуглуулах хяналтын хуудас (Phase 1 engine)

> **Зорилго.** SP зөвлөх engine ажиллахад шаардлагатай датаг 4 эх үүсвэрээр бүлэглэв. Эрэмбэ:
> **B (washability) → A (config) → D (калибраци) → C (түүхэн back-test).**
> Багана: *Талбар · Нэгж · Одоо мэдэгдэж буй · Хэрэгтэй юу · Хаашаа орох (форм/config)*.
> Хатуу дүрэм: бүх дата **гараар** орно (PLC холболтгүй, Phase 1). Engine эх үүсвэрийг мэдэхгүй — ижил талбар маргааш PLC tag-аас ирж болно.

## B. Seam бүрийн washability — давхарга бүрт нэг удаа ⭐ ХАМГИЙН ЧУХАЛ

Engine-ийн физик суурь. `washability-input.html` маягтаар нэг seam = нэг бичлэг. Doc 03 §12 `[DUK INPUT NEEDED]`.

**Seam бүрт:**

| Бүлэг | Талбарууд |
|-------|-----------|
| Таних | Seam код, Sample ID, блок, ширхэглэлийн хүрээ (ж −8+2мм), лаб |
| Raw чанарын толгой | TM%, IM%, Ash ad%, Vol ad%, Sulphur ad%, CSN, TRD |
| **Sink-float хүснэгт** | Нягтын 14 фракц тус бүрт: **Mass% ба Ash%** (нягт: float1.30 / 1.30–1.325 / … / 2.00–2.20 / sink2.20) |

> - Нягтын алхам нь LIMN 4AU тайлантай нийцсэн (cut орчим 0.025, захдаа бүдүүн). Маягт автоматаар RD, cum float yield/ash, NGM (±w)-г бодно.
> - **Хэдэн seam хэрэгтэй вэ?** Та одоо тэжээдэг blend-д орж буй бүх давхаргын washability. (Жишээ 4A, 0C, 6B гэх мэт.)
> - Шинэ давхарга нээгдэхэд лаб 24–48ц-д хариу гартал engine conservative low density руу шилждэг (Doc 02 мөр 439) — энэ хүртэл washability бэлэн болно.

## C. Ээлжийн оператор бичлэг + түүхэн дата (back-test)

`operator-input.html` маягтаар ээлж/2ц/12ц тутам. **Engine-ийг live холболтгүйгээр шалгахад** (back-test) эдгээрийн **түүхэн бичлэг** хэрэгтэй — олон ээлжийн {тэжээл → SP → үр дүн} мөр.

| Бүлэг | Талбар (нэгж) | Давтамж |
|-------|---------------|---------|
| Тэжээл | raw_ash%, чийг%, top_size мм, fines% | 2ц / ээлж |
| Blend | seam нэр + харьцаа % | ээлж |
| PV (одоо) | media density Pri/Sec, оролтын даралт Pri/Sec, feed flow, **pump speed Pri/Sec**, pump current, sump level, mag-sep current, belt scale t/h | real-time / ээлж |
| SP (тавьсан) | media density SP Pri/Sec, **pump speed SP Pri/Sec**, target ash коксжих/эрчим хүч | ээлж |
| Лаб | 2ц тэжээл/бүтээгдэхүүн ash, 12ц цикл, Pri/Sec OF ash, UF ash, чийг, тооцоолсон yield Pri/Sec | 2ц / 12ц |
| Элэгдэл | vortex Ø, spigot Ø, доторлогоо зузаан, циклон/насос run-hours, impeller төлөв 1–5 | 7 хоног / зогсолт |
| Гажиг | rope discharge, кавитаци, sump overflow, даралт савлалт, исэлдсэн нүүрс | тохиолдол бүр |

> **Back-test-д хамгийн үнэтэй:** олон долоо хоног/сарын түүхэн {тэжээлийн гарын үсэг → хэрэглэсэн SP → бодит yield/ash}. Энэ нь Tier-2 кейс сангийн суурь (Doc 02 §5.2.1) — "өмнө яаж угаасан" түүх washability-аас илүү найдвартай.

## D. Engine калибраци — түүхэн датанаас тааруулна (одоо [DEMO] placeholder)

Эдгээрийг шууд "бөглөхгүй" — түүхэн датанаас тохируулна, гэхдээ Дукийн инженерийн дүгнэлт эхний таамгийг өгнө. Одоо мокт демо утга суулгасан.

| Калибрацийн зүйл | Демо утга | Дукээс хэрэгтэй | Хаана |
|-------------------|-----------|----------------|-------|
| **Pump speed ↔ effective cut gain** | 0.004 g/cm³ / 1% VFD | 1% хурд (эсвэл 100 rpm) нэмэхэд d₅₀ хэр шилждэг вэ? | sp-recommendation `pumpGain` |
| **Spigot элэгдэл → d₅₀ уналт** | 0.60 g/cm³ / элэгдэл-фракц | Хошуу X% томрох → cut хэр хөнгөрдөг вэ? | `gainSpigot` |
| **Vortex элэгдэл → d₅₀ өсөлт + bypass** | 0.40; Ep 0.50 | Vortex томрох → cut/Ep хэр муудах вэ? | `gainVortex`, `epVortex` |
| **Baseline Ep (элэгдэлгүй)** | 0.030 | Эдгээр циклоны хэвийн Ep? | `epBase` |
| **Элэгдлийн амьдрал (солих хүртэл)** | vortex 10000ц / spigot 8000ц / impeller 4000ц | **Бодит running hours (эсвэл т)** солих хүртэл (Doc 03 §13) | `WEAR.life` |
| **Солих босго (диаметр)** | spigot +6%, vortex +5% | Ямар Ø өсөлт/доторлогоо зузаанд солих вэ? | `WEAR.thr` |
| NGM цонх (±w) | ±0.10 | LIMN template-тэй таарах конвенц | washability/sp маягт |

## Эхлэхэд санал болгох дараалал

1. **B — 2-3 үндсэн seam-ийн washability** хүснэгтийг `washability-input.html`-д оруул (engine физик суурь).
2. **A — Doc 03 дутуу config** (density хязгаар, насосны нэгж/хүрээ, бүтээгдэхүүний зорилт).
3. **D — элэгдлийн бодит амьдрал + pump↔cut харьцаа** (хоёр тоо engine-ийн цөм).
4. **C — 1-2 долоо хоногийн түүхэн ээлжийн бичлэг** back-test-д (сонголтоор, дараа).
